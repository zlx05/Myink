# 管理面板与写作观测

管理员登录后，从侧栏或账号页进入 `/admin`。管理员角色独立于普通/VIP任务调度等级：管理入口不会自动取消写作配额，也不赋予任意服务器命令执行权限。

## 权限

- 普通写作接口继续按作品归属隔离，包括管理员自己的日常写作。
- 专用管理接口可跨用户只读查看作品、章节正文、设定、任务和节点调试记录，不提供删除或修改他人作品的操作。
- 管理接口每次验证真实 Bearer 会话和数据库当前角色；浏览器缓存、请求中的自报角色或用户头不能授予权限。
- 管理访问留有审计记录，响应禁止缓存。用户环境、模型连接凭据、密码哈希不在管理接口返回。

服务器上的角色管理命令（只针对已存在账号）：

```sh
docker compose exec myink-api myink set-role zlx admin
```

变更角色会撤销该账号旧会话，需要重新登录。降为普通用户时将最后一个参数改为 `user`。密码重设继续使用交互式 `myink reset-password`，不要把密码写入命令参数、源码或部署文件。

容器启动使用 `myink init --no-seed`：升级结构但不重复创建示例账号。只有确实需要开发示例数据时才手工运行带种子的 `myink init`；不要在示例账号已经改名的实际库中使用该方式补数据。

## 阅读指标

- 总览、用户与作品统计来自数据库聚合；列表分页，正文和节点详情按需读取。
- `cost_est` 是已记录的费用估算，不是供应商账单；缺少价格或历史费用的记录不能据此推断真实花费。
- 节点耗时来自已记录的 `duration_ms`；零值可能表示没有测量。任务创建至最后更新的时间跨度包含排队、暂停和人工等待，不能视为纯模型运行时间。
- 全部节点列表还包括没有任务编号的建书、整书大纲等调用，不能只看任务列表。
- 新的输入、输出、工具调用和召回快照有大小上限，并展示脱敏/截断标记；历史未保存的部分不能事后补造。脱敏识别常见凭据字段与格式，不承诺识别正文中任意形式的秘密。
- 记录会随使用增长，部署时仍需规划存储容量、留存和归档；本次不自动删除历史记录。
- 大小限制针对新增调试快照与管理接口响应；原流程后续还要读取的规划、审核等业务字段保持完整存储，不受新增快照限额覆盖，以免观测改变写作决策。

## 公网部署边界

当前管理查询复用 `ADMIN_DATABASE_URL`，在管理员鉴权后开启只读事务，普通连接和RLS规则不变。应用层只读事务不等于数据库凭据最小权限；公网加固应拆出专用只读报表角色，并完成 [公网检查清单](PUBLIC-DEPLOYMENT-CHECKLIST.md)。增加管理面板不代表已经完成全部公网安全加固。
