# 管理员账号与全站写作观测

## 用户目标与权限边界

用户希望使用 zlx 登录系统管理后台，持续观察所有用户作品以及每次写作的节点、token、估算费用、耗时、规划、审核和召回依据，支持后续优化。密码由用户明确指定，不能写入源码、报告或镜像。最新确认：删除旧 zlx 账号及其1本作品和关联数据，不新建备份；把 demo（7本作品）原地改名为 zlx 并提升为管理员，保留其 UUID 和作品，其他账号不变。账号操作由主代理部署阶段在精确核验后完成。

这是新管理子系统，采用独立 /admin API 和面板；不把 require_owner 改成管理员通吃，不允许普通账户看别人的内容。角色独立于 normal/vip 调度等级，默认 user；仅通过服务器管理命令授予 admin。管理请求用真实 Bearer 会话和数据库当前角色逐次认证，不信任浏览器 localStorage、自报 role 或 X-Myink-User。权限变更撤销旧会话。管理面板主要是跨用户只读观测，不新增删除他人作品、执行任意服务器命令的功能。

## 密码

新注册、改密、服务器重设密码接受8–128字符，至少一个ASCII字母和一个数字；不要求大小写组合或特殊符号，也不禁止特殊符号。保留128字符上限用于资源保护。已有密码登录只检查合理长度，不能因新混合规则锁死旧账号。继续使用现有scrypt、限流和会话撤销。

## 管理后台与数据契约

独立路由 /admin ，入口仅向当前admin展示。包含总览、用户/作品筛选、全站任务筛选与节点时间线、书籍章节全文阅读。分页默认25、最多100；统计使用数据库聚合，不加载全部正文。费用明确为已有cost_est估算，不冒充供应商账单；任务时间区间包含等待/暂停，节点duration_ms显示已记录耗时，未记录不编造。

内部 /internal/v1/admin 对应公开 /api/v1/admin：

- GET /overview：用户、项目、章节、任务、运行次数、输入输出token、cost_est、duration_ms与任务状态分布。
- GET /users：分页账号列表及写作统计，支持q。
- GET /projects：分页作品、作者与统计，支持user_id/q。
- GET /projects/{project_id}/chapters：分页章节元数据；GET /projects/{project_id}/chapters/{chapter_id}：全文与摘要。
- GET /projects/{project_id}/context：设定、大纲及有界的事件/事实/人物数据，不包含模型连接或用户环境。
- GET /tasks：按user_id/project_id/status筛选分页，带统计。
- GET /tasks/{task_id}：任务摘要、清洗后的payload、错误与指标。
- GET /tasks/{task_id}/runs：分页节点元数据；GET /runs：按用户/作品/节点筛选的全部运行记录（包含task_id为空的建书/大纲调用）；GET /runs/{run_id}：单节点产物与安全调试内容。
- GET /access-logs：分页管理访问记录。

分页格式为 {items: [...], total: int, limit: int, offset: int}。不存在的资源404，非管理员403，缺失/失效Bearer401。所有管理路由设置no-store并写管理访问审计记录（actor/action/target/time），不记录密码或请求凭据。网页只文本渲染记录，禁止把用户/模型内容插入原始HTML。

跨用户聚合和全文查询使用已有管理数据库连接，但只在Bearer管理员校验之后开启只读事务（SET TRANSACTION READ ONLY），普通业务连接和RLS策略不变。访问审计另用普通连接写入。此实现仍依赖部署中的管理数据库凭据；公网加固应进一步拆出最小权限报表角色，不能把应用层只读事务宣称为完整数据库权限隔离。

## 观测内容

复用agent_runs既有节点/token/成本/耗时/错误/detail。为未来节点补充有界的模型输入输出与召回上下文快照（事实、事件、片段、plan_cast后实际上下文），规划/审核产物可回放；文本按预算截断并明确标记，不无限增长。统一清洗嵌套敏感字段及明显Bearer/API-key串，不公开password_hash、账号环境或模型连接凭据。历史缺失内容明确说明无法追溯补造。观测不改变生成决策与租户上下文。
